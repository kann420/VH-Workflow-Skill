Game Localization Workflow  ·  Quy trình Việt hóa game

Research → style guide → tiered batch editing → automatic validation → consistency pass → repack & install

PIPELINE 8 steps · 8 bước

1

Extract corpus

Trích xuất text

All strings → corpus.jsonl with EN, current VI, speaker, scene order. Prove a byte-identical rebuild first.

2

Research the story

Research cốt truyện (bắt buộc)

Bot-friendly sources (wikis, guides, reviews) + mining the game text → character bible: gender, age, relations, register.

3

Style guide

Cẩm nang văn phong

Xưng hô table, spoken vs written register, glossary, examples. Unknown gender → no gendered pronoun.

4

Batches

Chia lô

~15k source chars per batch. Dialogue grouped by scene so editors see who talks to whom.

then · tiếp theo
5

Tiered editing

Đội biên tập nhiều tầng

Lead → ≤5 coordinators → cheap workers for simple lines only. Output E/<batch>.partN.jsonl.

6

Validate & supervise

Kiểm tra & giám sát

Timings [0-2.5], tags, {vars} must survive. Spot-check samples, fix decisions centrally.

7

Consistency pass

Rà soát thống nhất

Merge edits, propagate duplicates, unify drifted terms with source-aware rules.

8

Pack & install

Đóng gói & cài

Rebuild game files, verify every entry, back up, install with the game closed.

Coordinators (≤5)Edit the hard material themselves: story scenes with complex pronouns, long documents, quest logs. Review every worker line.
Tự làm phần khó, duyệt toàn bộ bài của trợ lý.
Workers (≤3 per coordinator)Cheapest model (Haiku, Luna…). Simple lines only: UI labels, item names, barks, stat text, short choices.
Chỉ dịch câu đơn giản.
Why tiers?Story dialogue needs the strongest editor; UI text does not. Tiering saves most of the quota without hurting story lines.
Tiết kiệm quota mà giữ chất lượng.
